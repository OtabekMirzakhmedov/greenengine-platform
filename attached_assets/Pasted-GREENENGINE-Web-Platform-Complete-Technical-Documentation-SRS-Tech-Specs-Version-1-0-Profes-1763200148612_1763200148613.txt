GREENENGINE Web Platform — Complete Technical Documentation (SRS + Tech Specs)

Version 1.0 — Professional Edition

1. Introduction
1.1 Purpose

This document defines the full technical, functional, and non-functional requirements for the GREENENGINE Web Platform, developed and deployed on Replit Cloud. It serves as a unified reference for developers, content managers, administrators, and stakeholders.

1.2 Scope

The system provides a comprehensive portal for the GREENENGINE project, including:

Public website with structured project information

Storytelling pages for partner institutions

Action Plans, Events, Infographics, and Community Development sections

Intercultural Passport module

Content Management System (CMS) for administrators

API backend with secure authentication

SQL database using Prisma ORM

2. System Overview

The system consists of:

Frontend: React + Vite

Backend: Node.js (Express) + Prisma ORM

Database: PostgreSQL (Replit PostgreSQL or external DB)

Storage: Replit-hosted file system (or S3 alternative)

Authentication: JWT-based login

Deployment: Replit Nix environment

11. Content-Filling Guideline
General Writing Rules

Clear, formal academic tone

Use consistent terminology

Keep paragraphs short

Include visuals wherever possible

Images

Use high quality (max 1–2 MB)

Landscape orientation preferred

PDFs

Must include project logo

Should be named using convention:
GE_<Category>_<Institution>_<Year>.pdf

Stories Pages

Each institution should provide:

3–4 high-quality photos

1 short video (optional)

Overview (300–500 words)

Achievements (list or paragraph)

Events

Each event must include:

Agenda PDF

5–10 photos

Summary text

12. Replit Deployment Guide
1. Create Replit project

Create Node.js Repl for backend

Create React Repl for frontend

2. Install dependencies

Backend:
npm install express prisma @prisma/client bcrypt jsonwebtoken multer cors

Frontend:
npm install react-router-dom axios

3. Configure Prisma
npx prisma init
npx prisma migrate dev --name init

4. Configure environment variables

DATABASE_URL

JWT_SECRET

5. Run backend

node server.js

6. Run frontend

npm run dev
